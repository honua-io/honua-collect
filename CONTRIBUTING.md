# Contributing

**Honua Collect is not accepting code contributions at this time.** It is open
source under the Apache License 2.0, developed and copyrighted by Honua Geo Inc.,
and built on the Apache-2.0 Honua SDK and Mobile packages, which are separate
projects. Pull requests from outside the organization are closed automatically by
`.github/workflows/close-external-prs.yml`.

What is welcome:

- **Bug reports and feature requests** as GitHub issues. Use the issue templates;
  include the capability key when you know it.
- **Security findings** through the organization security policy at https://github.com/honua-io/.github/blob/main/SECURITY.md (security@honua.io). Do not open
  public issues for suspected vulnerabilities.
- **Interoperability reports** from client tooling (QGIS, ArcGIS, GDAL, OWSLib and
  others) as issues, with the request and response that misbehaved.
- **Questions and design feedback** on the open standards Honua implements, in the
  standards repositories: [geospatial-mcp](https://github.com/honua-io/geospatial-mcp)
  and [geospatial-grpc](https://github.com/honua-io/geospatial-grpc).

If you have a patch, describe the fix in an issue and we will implement it. You are free to
fork and customize Collect under the Apache License 2.0; see "Fork and customize" in
the README.

The SDKs, Console, Studio and the open protocol standards are also Apache-2.0 and have their
own contribution terms in their repositories.
